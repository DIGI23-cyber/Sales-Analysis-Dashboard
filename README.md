Superstore Sales Analytics Dashboard

Project Overview

This project analyzes Superstore sales data using Python and creates an interactive dashboard to understand business performance.

Technologies Used

- Python
- numpy
- Pandas
- Matplotlib
- streamlit
- Data Visualization

Project Features

- Business Overview
- Sales Analysis
- Profit Analysis
- Monthly Sales Trends
- Category Analysis
- Product Performance
- Sales Forecasting
- Business Recommendations

Project Files

- "project.py"
- "dashboard.py"
- "sample_-_superstore.csv"

Objective

To analyze sales data, identify business trends, and generate useful business insights.
